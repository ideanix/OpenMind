# OpenMind

Self-hosted shared memory server for AI coding agents, exposed over MCP.
Requirements live in `docs/REQUIREMENTS.md`; read them before proposing
architecture or code.

## Conventions

- Language: Go 1.24+, standard library first, official MCP Go SDK.
- Repo is public and English-only: code, comments, docs, commit messages.
- Do not commit or push unless explicitly asked.
- No Codex attribution lines in commits.
- Keep `docs/REQUIREMENTS.md` as the source of truth; update it when a
  decision changes scope, and record decisions under "Open questions" → resolved.
